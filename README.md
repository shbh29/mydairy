This project is something I have interest from long time. I want a dairy for my work journaling and personal journaling. I would like to have a small timer notification to remind me to journal. I did not find such project that allows me journal with a timer notification to remdind me to several interval. I did use different separate timers but then they were not connected to the journaling  status and I had to separately manage those two while working that did not provide a seamless experience. I want an app that allows me to journal without making me to think about time and also note the how I navigated through time while working. So, this is my attempt to try that idea. Please try using the app. I would appreciate your feedback. Please feel free to make it your own.
